main_project.chat.chat_grok.fetch_station_context(base_url: str) → str[source]

Fetch a live station summary to inject into the chatbot system prompt.

Calls the internal /api/stations endpoint and formats up to 50 stations as a compact plain-text block. Falls back to an empty string on any error so the chat endpoint continues to work without station context.

Parameters:

base_url – The application’s base URL (e.g. "http://127.0.0.1:8000").

Returns:

A plain-text summary string listing station names, available bikes, available spaces, and status. Returns an empty string if the endpoint is unreachable or returns no data.

main_project.chat.chat_grok.call_groq_with_retry(messages: list, api_key: str, max_retries: int = 3) → Response[source]

Send a chat completion request to the Groq API with retry logic.

Retries on connection timeouts, 429 rate-limit responses (honouring Retry-After headers), and 503 service-unavailable responses using exponential back-off.

Parameters:

  • messages – List of OpenAI-format message dicts (role + content).

  • api_key – Groq API key for the Authorization header.

  • max_retries – Maximum number of attempts before giving up. Defaults to 3.

Returns:

The final requests.Response object (successful or not). The caller is responsible for checking response.status_code.

Raises:

requests.exceptions.ConnectTimeout – If all retry attempts time out.

main_project.chat.chat_grok.chat() → tuple

POST /api/chat — Handle a chat completion request using the Groq LLM API.

Injects live Dublin Bikes station data into the system prompt, then forwards the conversation history to Groq and returns the assistant reply.

Uses:

  • fetch_station_context() — fetches live station data from GET /api/stations and formats it as a plain-text block for the system prompt.

  • call_groq_with_retry() — sends the message list to the Groq API with automatic retry on rate-limit and service errors.

Example request:

POST /api/chat
Content-Type: application/json

{
    "messages": [
        {"role": "user", "content": "Which station has the most bikes right now?"}
    ]
}
Parameters:

messages – List of OpenAI-format message dicts (JSON body, required). Each dict must have role ("user" or "assistant") and content.

Returns:

{"reply": str}, 200. On rate limit: {"error": ..., "message": ..., "retry_after_seconds": int}, 429. On other errors: {"error": str}, 400/500.

Return type:

A Flask JSON response tuple. On success
