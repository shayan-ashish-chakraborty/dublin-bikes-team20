main_project.station.services._forecast_series_start_on_the_hour(now: datetime) → datetime[source]

Return the first forecast timestep aligned to the next full clock hour.

If the current time is already exactly on the hour it is returned as-is; otherwise the next hour boundary is returned (e.g. 16:14 → 17:00).

Parameters:

now – The current local datetime.

Returns:

A datetime with minute, second, and microsecond set to zero, advanced by one hour if now is past the floor of the current hour.

main_project.station.services._weather_forecast_list_from_openweather(hours: int, now: datetime) → List[Dict[str, Any]] | None[source]

Build a per-hour weather series for the station forecast pipeline.

Uses the same hourly rows as the weather UI (via hourly_forecast_list_like_weather_page()). Timesteps are clock-hour aligned: starting from the next full hour if now is already past HH:00, then +1 h per step.

Parameters:

  • hours – Number of forecast steps to build (one per hour).

  • now – The current local datetime used to anchor the series start.

Returns:

A list of hours weather dicts, each with keys avg_temp, avg_humidity, avg_pressure, is_raining, and time ("YYYY-MM-DD HH:MM"). Returns None if the weather source (DB and OpenWeather API) is unavailable or returns no rows.

main_project.station.services.station_predict_from_request(request: flask.Request) → dict[source]

Run a multi-hour bike and dock availability prediction for one station.

Reads query parameters from the Flask request, fetches live station data, builds an hourly weather series, and runs the two-stage ML pipeline in batch mode.

Uses:

  • get_station() — fetches live station data and capacity from JCDecaux.

  • format_station() — normalises the raw station dict.

  • _forecast_series_start_on_the_hour() — computes the first forecast timestep aligned to the next full clock hour.

  • _weather_forecast_list_from_openweather() — builds the per-hour weather series (DB → OpenWeather fallback) used as wx_override for each forecast step.

  • _load_models() — loads the trained ML model tuple from disk.

  • _predict_bike_dock_batch() — runs the bike/dock models across all forecast hours in one batch call.

Parameters:

request –

The Flask Request object. Expected query parameters:

  • number (int, required): JCDecaux station ID.

  • hours (int, optional): Forecast horizon in hours. Clamped to [1, 48]. Defaults to 48.

Returns:

  • number (int): Station ID.

  • times (list[str]): ISO-formatted forecast timestamps.

  • predicted_bikes (list[float]): Predicted available bikes per hour.

  • predicted_docks (list[float]): Predicted available docks per hour.

  • predicted_temp (list[float]): Predicted temperature (°C).

  • predicted_humidity (list[float]): Predicted relative humidity (%).

  • predicted_pressure (list[float]): Predicted pressure (hPa).

  • predicted_rain (list[int]): Binary rain flag per hour.

Return type:

A dict with keys

Raises:

ValueError – If number is missing or invalid, station capacity is unavailable, ML models cannot be loaded, or weather data is unavailable.

main_project.station.routes.stations_predict()

GET /api/stations/predict — Run a multi-hour bike and dock prediction for one station.

Uses:

  • station_predict_from_request() — runs the full multi-hour ML pipeline and returns the forecast dict.

Example request:

GET /api/stations/predict?number=42&hours=8
Parameters:

  • number – JCDecaux station ID (query param, required).

  • hours – Forecast horizon in hours, max 48. Defaults to 48 (query param).

Returns:

JSON prediction dict from station_predict_from_request(), or an error JSON with status 400/503.
